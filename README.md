## 当前测试状态

截至 2026-04-14，`harness_meta` 当前全量测试结果为 `216/216` 通过。

当前测试不是单一类型，而是按下面三类逐步收紧：

1. `behavioral`：直接验证运行时行为、状态变化、Git 副作用和门禁阻断。
2. `anti-cheat`：验证“文案看起来像通过、结构看起来完整”但实际上不合规的输入会被拒绝。
3. `static`：只保留少量确实适合静态验证的常量、schema、版本号规则。

当前仓库的改造方向是：尽量减少低价值字符串断言，让关键规则更多由运行时 guard 和行为测试共同定义。
